# Frontend: учет деталей на складе

Клиентская часть курсовой работы «Разработка клиент-серверного приложения для учета деталей на складе предприятия».

## Стек

- React
- TypeScript
- Vite
- React Router
- Axios

## Установка зависимостей

Команды выполняются из папки `frontend`.

```powershell
npm install
```

## Переменные окружения

Создайте `.env` на основе `.env.example`:

```powershell
Copy-Item .env.example .env
```

Переменная `VITE_API_URL` задает адрес backend API:

```env
VITE_API_URL=http://localhost:8000
```

## Запуск dev-сервера

```powershell
npm run dev
```

После запуска frontend доступен по адресу:

```text
http://localhost:5173
```

Для работы страницы категорий должен быть запущен backend:

```text
http://localhost:8000
```

## Страница категорий

Страница доступна по адресу:

```text
http://localhost:5173/categories
```

## Страница деталей

Страница доступна по адресу:

```text
http://localhost:5173/details
```

Для работы страницы деталей должен быть запущен backend и заполнены справочники категорий, поставщиков и складов.

На странице реализованы:

- загрузка списка деталей из backend API;
- добавление детали с выбором категории, поставщика и склада;
- редактирование детали;
- удаление детали с подтверждением;
- быстрое изменение количества детали;
- фильтрация по поисковой строке, категории, поставщику и складу;
- отображение деталей с малым остатком по заданному порогу;
- сообщения загрузки, пустого списка и ошибок.

Примеры фильтров backend API, которые использует страница:

```text
/details?category_id=1
/details?search=bolt
/details/low-stock?threshold=5
```

## Роли доступа

На frontend реализовано демонстрационное управление доступом без backend-авторизации, JWT и серверных проверок.

Доступные роли:

- `admin` — может просматривать, добавлять, редактировать и удалять все сущности, а также менять количество деталей;
- `manager` — может просматривать все сущности и менять количество деталей, но не может добавлять, редактировать и удалять записи;
- `viewer` — может только просматривать данные.

Текущая роль выбирается в верхней панели приложения. Выбранное значение сохраняется в `localStorage`, поэтому роль сохраняется после перезагрузки страницы. По умолчанию используется роль `viewer`.
